glossary

revision lag 12
How many revisions Check's data trails the latest write.
subjectset file:design.md#viewer
A set named by a resource and a relation. Checks ask whether a subject is a member.
objective
A target for one service, measured over 30 days.
error budget
The failures an objective allows before it's missed.
p99
The time within which 99 of every 100 requests finish.
saturation
How much of a shared resource, such as table capacity, is in use.
serious
An alert about a write that may have added members to a sensitive subjectset. Review it now.
notice
An alert about a pattern worth a look, with no memberships changed.
revision 1043
A position on the revision clock. Every write gets one.
